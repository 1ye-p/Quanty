### 6. 自省分析

#### 我不确定的工作

1. **策略间信号冲突的具体规则**：
   - PRD 提到"entry 信号优先于 add_position"，但未定义：
     - 如果 entry 策略触发卖出，add_position 策略触发买入，如何处理？
     - 是否需要定义信号优先级矩阵？
   - **建议**：补充信号优先级矩阵

2. **全局止盈止损的触发时机**：
   - PRD 提到"每个交易日开始时检查"，但未定义：
     - 如果持仓浮盈达到 20%，但策略 B 的买入信号同时触发，如何处理？
     - 全局止盈止损是否支持动态调整？
   - **建议**：补充触发时机的详细说明

3. **交易归因的数据模型**：
   - PRD 提到"每笔交易记录来源策略 ID"，但未定义：
     - 需要新增数据库表还是扩展现有表？
     - 归因信息是否需要持久化？
     - 如何处理策略级止盈止损触发的交易？
   - **建议**：补充数据模型设计

4. **组合策略的深拷贝**：
   - PRD 未定义子策略的深拷贝机制：
     - 参数扫描时，如何克隆组合策略？
     - 子策略的状态如何隔离？
   - **建议**：补充深拷贝机制
