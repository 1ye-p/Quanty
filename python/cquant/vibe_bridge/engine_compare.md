> 生成时间：2026-05-22
> 对比版本：Vibe-Trading HEAD vs cQuant fill_simulator.py + costs.py

## 规则对比表

| 规则 | Vibe ChinaAEngine | cQuant AShareFillSimulator | 差距/建议 |
|------|---------|--------|------|
| **T+1** | `entry_date vs current_bar_date` 比较 | `buy_dates` dict 追踪买入日期 | 逻辑等价 |
| **涨跌停检测** | 按板块动态（ChiNext/STAR 20%, BSE 30%, ST 5%） | `limit_rules.py` 动态检测 + `close==high/low` 验证 | cQuant 更严格（双重验证） |
| **ST 限制** | heuristic（代码后缀判断） | 同 | 相同 |
| **停牌处理** | ❌ 不检查 | ✅ `is_suspended` 列阻断交易 | **cQuant 更完善** |
| **价格有效性** | ❌ 无检查 | ✅ 拒绝 >30% 偏离 prev_close 的价格 | **cQuant 更完善** |
| **买卖顺序** | 未明确指定 | sells-before-buys（先卖后买释放资金） | **cQuant 更合理** |
| **最小手数** | 100 股 | 100 股 | 相同 |
| **涨跌停方向** | 限涨不买，限跌不卖 | 同 | 相同 |

## 关键差异分析

### 1. 印花税率（需更新）

**现状**：cQuant 使用 0.1%（千1），但 2023-08-28 起 A 股印花税已从 0.1% 降至 0.05%。

**建议**：更新 `costs.py` 中 `stamp_duty_rate` 为 `Decimal("0.0005")`。

**影响**：所有回测结果的卖出成本减半，对换手率高的策略影响较大。

### 2. 佣金率（可选微调）

**现状**：cQuant 使用 0.03%（万3），Vibe 使用 0.025%（万2.5）。

**建议**：保持 0.03% 或提供配置选项。万3 为行业默认，万2.5 为优惠费率。

### 3. 滑点（建议调整）

**现状**：cQuant 默认 0.01%（万1），Vibe 默认 0.1%（千1）。

**建议**：cQuant 的 0.01% 偏低，建议调整为 0.05%（万5）更保守。对于流动性差的股票，0.1% 更现实。

### 4. cQuant 独有优势（保持）

- **停牌检查**：阻止在停牌日交易，避免虚假信号
- **价格有效性**：拒绝异常价格（>30% 偏离），防止数据质量问题
- **sells-before-buys**：先卖出释放资金再买入，更符合实际操作
